# Proposal

## Why

課堂上原本讓各組學生輪流上台把 Guided Notes 的答案寫在黑板上，流程耗時，也難以公平判定誰先作答。本專題要做一套在本機執行的「課堂搶答系統」，含老師端與學生端。專題分工由其他組員負責後端，本 change 負責前端介面，以及一個依「前端介面約定 v0 草案」實作的 mock 後端。有了 mock 後端，前端可以在真正的後端完成前獨立開發，並先用自動化測試驗收。

核心原則：**前端不自己判斷規則，只負責呈現。** 順位、組長、能否作答、可見性一律以後端快照為準；前端停用按鈕只是為了操作體驗，不能當作規則的保障。

## What Changes

**老師端**
- 教師登入頁（密碼交由後端驗證，前端不存放任何密碼）。
- 上傳從 Google Sheets 下載的 `.xlsx`，並顯示後端回傳的解析預覽：題數、「題號 → 工作表!儲存格」對照（題組會列出各子填空）、warnings、解析錯誤原因。
- 設定組數、確認建立活動，並顯示後端產生的活動代號。
- 題目看板：
  - 各題狀態（未開始／進行中／已結束）
  - 開始、結束、重開、下一題
  - 各組即時作答狀態（未作答／編輯中／已送出）與順位
  - 組員名單、組長在線狀態、轉移組長
- 匯出寫回答案的 Excel，以及下載 CSV（檔案由後端產生，前端只觸發下載）。

**學生端**
- 輸入活動代號與暱稱加入活動。
- 用下拉選單選組：開始前可以換組，第一題開始後鎖定；組別記在 Cookie `group_<代號>`，只用於預選，以後端回傳的值為準。
- 等待畫面：顯示組員和組長，看不到其他組。
- 作答畫面：單題顯示 1 個輸入框，題組依子填空數量顯示多個輸入框。同組成員可以同時編輯共用草稿，只有組長能送出；組員會看到「只有組長能送出」的提示。
- 已送出後切換為唯讀畫面，不顯示順位。
- 題目結束後自動切到結果頁，顯示各組答案、順位與勝出組。

**共通**
- 以 Socket.IO 接收後端推送的狀態快照，整份替換本機狀態後重畫畫面。
- 顯示連線狀態；斷線時停用操作；重新連線或 `version` 跳號時重新取得快照。
- 前端輸入驗證是第一道防線：trim 時涵蓋全形空白與零寬字元、題組每格必填、500 字上限、防止連點。後端的錯誤碼都有對應的提示。

**開發與測試**
- 開發用 mock 後端（Express + Socket.IO，只存在記憶體），完整實作介面約定 v0，並內建情境腳本（例如兩組同時送出、組長斷線、後端拒絕換組）。
- 以 Playwright 的多個 browser context 模擬老師與多位學生，測試先對 mock 後端執行。
- README 說明本機啟動方式；`.env.example` 只放佔位值，`.env` 列入 `.gitignore`。

**不在範圍內（由後端負責）**
- 教師密碼驗證與 session 管理
- 活動代號產生
- 活動與題目的狀態機
- 搶答順位判定
- 後端的可見性控管（不把他組資料送給學生）
- 最後一道空白答案檢查與其他送出規則判定
- Guided Notes Excel 解析與答案寫回
- CSV 產生
- 資料保存

此外，「更公平的順位機制」等額外功能也不在本 change 範圍。

## Capabilities

### New Capabilities
- `teacher-console`：老師端畫面。涵蓋登入、上傳與解析預覽、建立活動、題目看板控制、各組即時狀態與組長管理，以及觸發匯出下載。
- `student-participation`：學生端畫面。涵蓋加入活動、選組與換組鎖定、等待、單題與題組作答、同組草稿共編、組長送出、已送出唯讀與結果檢視。
- `live-state-sync`：前端與後端的即時同步行為。涵蓋依快照呈現、`version` 跳號與重連時重新同步、連線狀態顯示、多瀏覽器階段一致，以及不保存、不洩漏他組資料。
- `mock-backend`：開發與測試用的 mock 後端。依介面約定 v0 提供 REST 與 Socket.IO 行為，並提供可重現的情境腳本供前端開發與自動化測試使用。

### Modified Capabilities

（無，專案目前沒有既有的 spec。）

## Impact

- **新增程式碼**：
  - 前端專案：Vite + Vue 3，含頁面、狀態管理、Socket.IO 用戶端。
  - mock 後端：Node.js、Express、Socket.IO。
  - Playwright 端對端測試。
- **新增相依套件**：`vue`、`vue-router`、`vite`、`socket.io-client`；mock 後端使用 `express`、`socket.io`、`multer`、`cookie-parser`；測試使用 `@playwright/test`。
- **對外介面**：本 change 定義「前端介面約定 v0 草案」（REST 路徑、錯誤碼、快照格式、Socket.IO 事件），寫在 design.md。後端組員確認後，如果有修改，以 `openspec-update-change` 同步更新本 change。
- **測試資料**：`samples/` 中的兩份範本（單題、題組）作為 mock 後端預覽資料和測試的參考來源。
- **機敏資訊**：前端與 repo 不含任何密碼或金鑰；mock 後端的教師密碼從 `.env` 讀取。
